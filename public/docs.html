01. Introduction

The InTTO Automated Certificate System is a modern web-based platform tailored to streamline event management, feedback collection, automated certificate generation with embedded verification QR codes, and authenticity tracking. This documentation outlines system architecture, admin workflows, participant flows, and component configurations.

02. Usage Workflows

Admin Panel & Event Builder

  • Log in securely using admin credentials.
  • Create events with detailed scheduling and location info via a multi-step builder.
  • Build customized feedback forms and survey questions.
  • Upload templates and position name/QR placeholders using Konva.js.
  • Launch dynamic event QR codes and monitor scan-to-response rates in real time.
  • Export participant survey and metrics data.

Participant Flow & Claiming

  • Scan the unique live-updating event QR code to open the feedback questionnaire.
  • Submit feedback answers and confirm participant details.
  • Instantly trigger async composite certificate rendering (including high-error-correction QR codes and central InTTO badge branding).
  • Preview and download your personalized, verifiable certificate.

Verification & Repository

  • Scan certificate QR codes to instantly route to verification endpoints.
  • Query the participant database to validate certificate authenticity and issuer status.

03. API & Architecture

Certificate Engine & Canvas Rendering

The system utilizes Konva.js for template visual positioning. Dynamic certificate compilation handles asynchronous composite asset rendering via certificate-gen.js, injecting custom participant data fields alongside verification QR codes containing unique route verification links.

Data Storage & Backend Services

  • Firebase Firestore: Persists event schedules, dynamic parameters, participant tracking, and survey response matrices.
  • Cloudinary: Secures and hosts uploaded certificate template visual assets.

04. Frequently Asked Questions

Q: How do I report system bugs?

A: Please open an issue on the official project repository.

Q: How do I generate certificates for a newly scheduled event?

A: Use the multi-step Event Builder in the admin dashboard to input event details, configure survey questions, upload a template, and deploy.

Q: Can participants download certificates directly?

A: Yes, completion of the survey flow automatically generates and renders the custom certificate for instant preview and download.

Q: How is certificate authenticity verified?

A: Scanning the embedded certificate QR code checks the participant database to validate issue status under UC InTTO.

Q: What file formats are supported for certificate templates?

A: High-resolution PNG and JPEG images are supported, with PNG recommended for optimal visual fidelity.
